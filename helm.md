# Helm: Build, Package, Push to Nexus, Repo Add and Deploy

Placeholders: replace `NEXUS` with your Nexus address (for example `20.x.x.x:8081`), and `mychart` with your chart name.

```
  helm create --> edit --> helm lint --> helm package --> curl push --> Nexus
                                                                          |
  AKS  <--  helm install  <--  helm repo add / update / search  <---------+
```

---

## Step 1: Prerequisites

```bash
helm version                    # Helm 3.x installed
kubectl get nodes               # connected to the AKS cluster
az aks get-credentials -g rg-aks-demo -n aks-nexus-demo --overwrite-existing
```

Nexus needs a **Helm (hosted)** repository:

1. Nexus UI > Settings (gear) > Repositories > Create repository > **helm (hosted)**
2. Name: `helm-hosted`
3. Deployment policy: **Allow redeploy** (while learning)
4. Save

Repo URL: `http://NEXUS/repository/helm-hosted/`

---

## Step 2: Build (create the chart)

```bash
helm create mychart
```

Edit `mychart/Chart.yaml`:

```yaml
apiVersion: v2
name: mychart
description: My demo chart
type: application
version: 0.1.0          # chart version, this is what Nexus stores
appVersion: "1.0.0"     # version of the app inside the chart
```

Edit `mychart/values.yaml` (key parts):

```yaml
replicaCount: 2

image:
  repository: nginx
  pullPolicy: IfNotPresent
  tag: "1.27"

service:
  type: LoadBalancer    # public IP on AKS
  port: 80
```

Check the chart before packaging:

```bash
helm lint mychart                         # find errors
helm template myapp ./mychart             # render YAML locally (nothing deployed)
```

---

## Step 3: Package

```bash
helm package mychart
```

Output: `mychart-0.1.0.tgz` in the current folder.

Optional version override:

```bash
helm package mychart --version 0.1.1 --app-version 1.0.1
```

Every new push needs a new version, because a version in Nexus should not be overwritten.

---

## Step 4: Push to Nexus

```bash
read -s -p "Nexus password: " NEXUS_PASS; echo

curl -u admin:$NEXUS_PASS \
  http://NEXUS/repository/helm-hosted/ \
  --upload-file mychart-0.1.0.tgz
```

- No output and no error means the upload worked.
- Verify: Nexus UI > Browse > `helm-hosted` should list `mychart-0.1.0.tgz`.
- Index file generated by Nexus: `http://NEXUS/repository/helm-hosted/index.yaml`.
- Add `-v` to curl to see the HTTP status when something fails.

---

## Step 5: Repo add

```bash
helm repo add mynexus http://NEXUS/repository/helm-hosted/ \
  --username admin --password $NEXUS_PASS

helm repo update
helm repo list
helm search repo mynexus
helm search repo mynexus/mychart --versions
```

Download without installing (optional):

```bash
helm pull mynexus/mychart --version 0.1.0 --untar
```

---

## Step 6: Deploy to AKS

```bash
helm install myapp mynexus/mychart --version 0.1.0 -n demo --create-namespace
```

Verify:

```bash
helm list -n demo
kubectl get pods -n demo
kubectl get svc -n demo -w          # wait for EXTERNAL-IP, then open http://<EXTERNAL-IP>
```

Override values at install time:

```bash
helm install myapp mynexus/mychart --version 0.1.0 -n demo --create-namespace \
  --set replicaCount=3 --set image.tag=1.26
```

---

## Step 7: Release a new version (upgrade and rollback)

```bash
# 1. change chart or values, set version: 0.1.1 in Chart.yaml
helm lint mychart
helm package mychart                                   # mychart-0.1.1.tgz

# 2. push
curl -u admin:$NEXUS_PASS http://NEXUS/repository/helm-hosted/ --upload-file mychart-0.1.1.tgz

# 3. refresh and upgrade
helm repo update
helm upgrade myapp mynexus/mychart --version 0.1.1 -n demo

# 4. history and rollback
helm history myapp -n demo
helm rollback myapp 1 -n demo
```

Remove the release:

```bash
helm uninstall myapp -n demo
```

## Troubleshooting

| Problem | Cause and fix |
|---------|---------------|
| `400 Repository does not allow updating assets` | Same version pushed twice. Bump the version or enable Allow redeploy |
| `401 Unauthorized` | Wrong user or password. Use the new admin password you set after first login |
| `403 Forbidden` | User lacks privileges. Add `nx-repository-view-helm-*-*` to the user's role |
| `404 Not Found` | Wrong repo name or URL. Open the URL in a browser |
| `not a valid chart repository` | URL does not point to a helm (hosted) repo, or credentials are missing |
| `chart "mychart" version "x" not found` | Run `helm repo update`, then `helm search repo mynexus --versions` |
| `cannot re-use a name that is still in use` | Release name exists. Use `helm upgrade --install` or a new name |
| Service shows `<pending>` | Wait a few minutes. Check `kubectl describe svc -n demo` |
| `ImagePullBackOff` | Wrong image name or tag in `values.yaml` |
| `helm: Permission denied` (Git Bash on Windows) | Chocolatey shim is blocked. Use `helm.exe` from your user folder (for example `$HOME/bin`) and add it to PATH |
